# 🐍 Snake Game

Un petit jeu **Snake** développé en **HTML, CSS et JavaScript** utilisant l’élément `<canvas>`.

---

## 🎮 Fonctionnalités

* Déplacement du serpent avec les flèches du clavier ⌨️
* Génération aléatoire de la nourriture 🍎
* Système de score en temps réel 📊
* Détection des collisions (mur et corps) 💥
* Sauvegarde du meilleur score avec `localStorage` 💾

---

## 📁 Structure du projet

```
snake-game/
│
├── index.html   # Structure de la page
├── style.css    # Design du jeu
└── script.js    # Logique du jeu
```

---

## 🚀 Lancer le projet

1. Télécharger ou cloner le projet :

```bash
git clone https://github.com/TON_USERNAME/snake-game.git
```

2. Ouvrir le fichier `index.html` dans votre navigateur.

---

## 🎯 Comment jouer

* Cliquer sur le bouton **Start**
* Utiliser les touches :

  * ⬆️ Haut
  * ⬇️ Bas
  * ⬅️ Gauche
  * ➡️ Droite
* Manger la nourriture pour augmenter le score
* Éviter les murs et le corps du serpent

---

## 🏆 Score

* Le score augmente à chaque nourriture mangée
* Le meilleur score est sauvegardé automatiquement
